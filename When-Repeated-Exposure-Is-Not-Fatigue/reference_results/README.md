# Reference results

These CSV files are the results used for the manuscript tables. They are
included so that reviewers can inspect the reported estimates without
redistributing the KuaiRec interaction data.

`paper_results.md` is a compact rendering of the representative association
and threshold results. `paper_table.csv` contains the representative rows in
machine-readable form, and `table_associations.tex` can replace Table 2 in the
manuscript. The other CSV files contain the complete model output used to
construct the summary.

Small differences in the final decimal place can occur with different BLAS
implementations. The package pins the Python dependencies used for the
submitted results.
